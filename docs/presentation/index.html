REFLECTION

Check early, measure widely, repeat the experiments

What worked

≈ 8×faster per request with parallel research: ~26 → ~3.3 min
  • Code decides “done”: 2 of 4 → 6 of 6 requests completed
  • Repeat guard: repeated calls 50 → 5
  • Missed requirements are reported, not hidden

What did not

8 of 12newsroom requests missed at least one requirement
  • Each review round found new points, so time ran out before fixes landed
  • Drafts grew during review: 1,569 words vs 900–1,200 allowed
  • The 270 s budget is soft: some runs took 350 s

What we learned

8 → 1same task scored 8 in one run and 1 in another: one run is noise
  • Drafts outgrew limits, so check requirements when work is handed out
  • Review time was not the real problem, so measure all scenarios first
  • One run is noise, so repeat each experiment
